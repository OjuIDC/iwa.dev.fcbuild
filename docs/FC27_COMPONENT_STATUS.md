# FC 27 Platform Component Status Matrix

This matrix records the authoritative implementation, runtime, network, persistence, and deployment-validation status of every material component in `iwa.dev.fcbuild` as of commit `764d95687d0ccf848ec5b52fbb19638cc38123e4`.

## Classification Legend
- `IMPLEMENTED` — Implemented in executable source code and verified by automated tests.
- `PARTIAL` — Core foundation or interface exists in source, but dependent stages or live integrations remain gated/incomplete.
- `PROPOSED` — Specified in design/roadmap only; not implemented in active runtime code.
- `DEFERRED` — Intentionally postponed to a subsequent gated phase.
- `DISABLED` — Code exists in repository, but runtime execution is disabled by default-off feature flags and/or fail-closed activation gates.
- `REJECTED` — Evaluated and explicitly prohibited by security, privacy, or legal boundaries.
- `SUPERSEDED` — Replaced by a newer authoritative component.
- `ARCHIVED` — Historical material moved to `docs/archive/`.
- `NOT_FOUND` — Not present in the repository.
- *Deployment Note*: Components marked `IMPLEMENTED_NOT_DEPLOYMENT_VALIDATED` in the notes have passing unit/integration/PostgreSQL tests and static Compose verification, but full-stack multi-container target-host deployment has not been executed in production.
