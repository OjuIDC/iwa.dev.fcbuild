# FC 27 Documentation Truth Table

This table records the accuracy audit, conflicts identified against executable source/migrations/tests, required corrections, and archive decisions for every significant documentation file in `iwa.dev.fcbuild`.

## Accuracy Classifications
- `CURRENT` — Accurate and aligned with executable code, migrations `0001`–`0012`, grants policy version `14`, and current tests.
- `CURRENT_WITH_CORRECTIONS` — Authoritative document retained in place and updated during this phase to resolve stale or incomplete statements.
- `HISTORICAL` — Completed milestone report, audit note, or dated test snapshot moved to `docs/archive/`.
- `SUPERSEDED` — Replaced by a newer consolidated architectural, operational, or security reference and moved to `docs/archive/`.
- `SPECULATIVE` — Contains unverified tactical or architectural hypotheses; restated in `docs/FC27_TACTICAL_HYPOTHESES.md` or archived.
- `DUPLICATIVE` — Overlapped with consolidated authoritative guides; merged and archived.
- `CONTRADICTORY` — Contained statements contradicted by current source/migrations; either corrected in place or archived with a non-authoritative notice.
- `UNVERIFIED` — Documents an external interface or empirical gate that remains intentionally unverified (`docs/EA_PLAYER_IDENTITY_VERIFICATION.md`).
